# The Add One Colour Design Kit

Two quiet colours, then one loud one. This kit is how BOXX Automations makes the three-colour website heroes in
the "Add One Colour" reels: Claude plans the designs and writes the briefs, ChatGPT makes the images.

## What's inside
- `SKILL.md`: the Claude skill. Plans three designs (subjects, palettes, colour names, mini story), writes one
  ChatGPT brief per design, checks the images that come back, and can write the reel script.
- `chatgpt-image-instructions.md`: the instructions for your ChatGPT image Project. It makes each design as a
  two-colour image plus an accent version of the same image.

## Set up (5 minutes, once)
1. **ChatGPT:** create a Project (e.g. "Add One Colour images") and paste `chatgpt-image-instructions.md` into its
   instructions.
2. **Claude:** either zip this folder and upload it as a skill in Claude's settings, or create a Claude Project
   and paste `SKILL.md` into its instructions.

## Use it
1. In Claude: "Plan 3 Add One Colour hero designs for a barbershop, a lemonade stand and a raincoat brand."
2. Pick one option per design. Claude locks the palettes and writes three ChatGPT briefs.
3. Paste each brief into your ChatGPT Project. Each one returns two images: two-colour and accent.
4. Bring all six images back to Claude to check spelling, alignment and stray colours.
5. Use them as they are: phase 1 is a flat block of the background colour, phase 2 the two-colour image,
   phase 3 the accent image.

## The trick
Cool page, warm accent. Warm page, cool accent.
